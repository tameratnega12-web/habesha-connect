# Habesha Agenagn V7.8.198

Targeted update: Reverse Rental Matching

- Rent seekers can post what they need to rent from their home page.
- Admin approves each Rental Wanted request in the existing Admin Verification Center.
- Approved requests appear once on every property owner home page.
- Property owners can offer one of their own approved properties.
- The seeker accepts or declines from the seeker home page.
- After acceptance, the owner clicks Agree and can view seeker contact information.
- The seeker then clicks Agree and can view owner contact information.
- Each side's contact information is released only after that side clicks its own Agree button.
- Existing property posting and rental request flow remains unchanged.
- No new SQL is required; the flow uses the existing properties and rental_requests tables.
