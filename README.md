# Habesha Connect V7.0.1 Role Dashboard Layout Polish

This release reorganizes the role-specific pages so each user sees the right workflow order and only their own information.

## Changes
- Traveler shipping page: Post Trip first, then Shipment Requests, My Traveler Trips, role-specific Shipping Connect boxes, and traveler note.
- Sender shipping page: Search Filters first, then Available Traveler Trips, Shipment Requests, sender-only Shipping Connect box, and shipping note.
- Owner rentals page: Add Property first, then Available Rent Seekers, My Properties, Rental Requests/Contacts, and Owner-only performance boxes.
- Rent Seeker rentals page: Search Filters first, then Available Owners/Rentals, Rental Requests/Contacts, and Seeker-only activity boxes.
- Admin remains unchanged and still sees total platform information.

No SQL migration is required.
