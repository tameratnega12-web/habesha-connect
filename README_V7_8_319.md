# Habesha Agenagn V7.8.319 — Clean Rentals Rebuild

This version starts from V7.8.318 where the previous property Rental system was removed.

## Install
Run `supabase/v7_8_319_rentals_clean_rebuild.sql` once in Supabase SQL Editor, then deploy this project.

## Rental flow
Property Owner posts property with up to six photos → Admin approves/rejects → Rent Seeker requests → Property Owner accepts/declines → accepted seeker requests owner information.

Only the property Rentals category was added. Trucking trailer rentals are unchanged.
