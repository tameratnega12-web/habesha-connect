# Habesha Agenagn V7.8.250

## Event Organizer photo gallery

- Event organizers can upload up to 6 event flyers/photos directly from phone or computer.
- Multiple photos can be selected at once.
- The owner can use Choose Files again to add more photos before submitting.
- Duplicate file selections are ignored.
- A selected photo can be removed before submission.
- Choosing photos on a phone no longer closes or refreshes the event form.
- Event photos appear in the approved public event card.
- Customers can tap/click a photo to open a large full-screen view.
- Business Directory gallery behavior remains unchanged.
- No other service categories were changed.

## Required SQL

Run `supabase/v7_8_250_event_photo_gallery_storage.sql` in the Supabase SQL Editor before testing event photo uploads.
