V7.8.124 - Direct Home Service request status and accepted activity.

Changes made only to direct requests for a listed Home Service provider:
- Customer Request Service form still emails Admin and waits for Admin approval.
- After Admin approval, the selected provider is notified and sees Accept / Decline at the top below How It Works.
- After provider acceptance, the accepted request appears at the top below How It Works for both customer and provider.
- The same provider listing no longer continues showing Request Service to that customer.
- The listing button changes to Waiting for Admin, Waiting for Provider, or Accepted.
- Duplicate active requests for the same provider service are blocked.
- No SQL required.
