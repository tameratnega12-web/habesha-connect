# Habesha Agenagn V7.8.211

## Sender-posted shipping item dual agreement

- Traveler accepts an approved sender-posted item.
- Sender sees an Agree button on the Sender home page.
- Sender sees traveler information only after clicking Agree.
- Traveler then sees an Agree button on the Traveler home page.
- Traveler sees sender information only after clicking Agree.
- Payment becomes available only after both users agree.
- No SQL is required.
