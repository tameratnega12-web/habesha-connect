# Habesha Agenagn V7.8.145

Built from V7.8.144.

Change in this version:
- Truck owners now see admin-approved trailers available for rent in **Your New Activity** immediately after signing in.
- The trailer card opens the Trucking dashboard, matching the truck-driver experience.
- A truck owner's own trailer listing is not shown as an available rental opportunity to themselves.
- Existing trucking, trailer, and all other category workflows are unchanged.
- Mobile and desktop layouts are supported.
- No new SQL is required.
