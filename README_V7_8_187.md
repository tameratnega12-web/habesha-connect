# Habesha Agenagn V7.8.187

Targeted Rentals update only:
- When a rental request is accepted and the property becomes Rented, the seeker receives a congratulations email.
- The email does not expose the owner's phone or email.
- The seeker dashboard shows one **Request Owner Information** button below the Rentals introduction/how-it-works area.
- Only the approved seeker can click the button.
- Clicking it immediately releases the owner's name, phone, and email and records the release in Supabase using the rental request status.
- The property owner receives a notice/email that the approved seeker requested the contact information.
- The layout uses the existing responsive cards/buttons and works on desktop and mobile.
